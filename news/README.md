# Campfire Patch Digest

This is a free, publicly readable editorial digest. Campfire presents original explanations of selected facts and links to the full official posts. No official article bodies, forum replies, game images, accounts, payments or analytics are hosted here.

The public app feed uses schema 2. Preserve stable note IDs and original source timestamps. Source review time, Campfire publication time and app download time are separate.

Review changes before committing. Each note requires an official source link and editorial approval. Never relabel an announced fix as delivered without supporting evidence. Update the source revision and review time only from actual evidence.

Use the validated publication tool in the Campfire workspace to stage the next digest. It preserves each source’s first Campfire publication date, advances its Campfire update date only for changed summaries, recomputes its semantic revision, and increases the feed sequence. Regenerate this human-readable page from the same entries.

The app rejects invalid, regressing or unreviewed envelopes and keeps its previous cache. Updating this public static digest does not require a new app build. It requires editorial review and a new commit; this initial release creates no new automation or paid service.
